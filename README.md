### Grand Coffee – Responsive Coffee Shop Website

Grand Coffee is a modern, responsive coffee shop website designed to provide customers with an attractive and user-friendly online experience. The website presents the coffee brand, its services, gallery, customer testimonials, contact information, and location in a clean and professional layout.

The website is built using **HTML5, CSS3, Bootstrap 5, JavaScript, Font Awesome, and Swiper.js**. It features a fully responsive design that adapts smoothly to **desktop, tablet, and mobile devices**.

### Main Features

* **Responsive Navigation Bar** – Includes the Grand Coffee logo, navigation links, and search functionality with a mobile-friendly layout.
* **Hero Section** – A visually attractive homepage banner with a coffee-themed background, heading, description, and call-to-action button.
* **About Us Section** – Provides information about the coffee shop along with an attractive image and descriptive content.
* **Gallery Section** – Displays coffee and café images in a responsive grid layout that adjusts according to screen size.
* **Services Section** – Highlights different services offered by the coffee shop using professional service cards and interactive hover effects.
* **Customer Testimonials** – Uses **Swiper.js** to create an interactive and responsive testimonial slider where customer reviews can be displayed.
* **Contact Section** – Includes a contact form where users can enter their name, email, subject, and message.
* **Google Maps Integration** – Displays the coffee shop's location directly on the website using an embedded Google Map.
* **Footer Section** – Contains useful links, contact information, social media icons, and copyright information.

### Technologies Used

* HTML5
* CSS3
* Bootstrap 5.3
* JavaScript
* Font Awesome
* Swiper.js
* Google Maps Embed

### Responsive Design

The main objective of this project is to create a professional online presence for a coffee shop where visitors can explore the brand, view coffee and café images, learn about available services, read customer testimonials, contact the business, and find its location easily.

Overall, Grand Coffee demonstrates practical front-end development skills including **responsive web design, modern UI layout, Bootstrap integration, interactive components, image galleries, sliders, forms, and Google Maps integration**.
